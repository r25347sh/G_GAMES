# ShadowScript リファレンス

**難易度: ★★★★☆（難解・圧縮）**

すべての命令が**1文字**のエソテリック言語です。文字数が極端に少なく、相手画面に透けて見えても一見して挙動が解読しにくい「影」のステルス性を持ちます。

---

## 命令表

### 数値・スタック

| 文字 | 意味 |
|------|------|
| `0`〜`9` | 数値をプッシュ |
| `_` | 0 をプッシュ |
| `d` | 複製 (dup) |
| `s` | 交換 (swap) |
| `p` | 破棄 (pop) |

### 算術・比較

| 文字 | 意味 |
|------|------|
| `+` `-` `*` `/` `%` | 四則・剰余 |
| `n` | 符号反転 |
| `=` `<` `>` | 比較（真=1 / 偽=0） |
| `!` | 論理否定 |

### センサー（値をスタックへ）

| 文字 | 意味 |
|------|------|
| `D` | 距離 (dist) |
| `A` | 相対角度 (angle) |
| `L` | 偏差角 (lead) |
| `E` | エネルギー |
| `H` | ヒート |
| `W` | 最近壁距離 |
| `T` | 時間 |
| `X` `Y` | 相対座標 |

### アクション

| 文字 | 意味 |
|------|------|
| `t` | 推力（値を pop、なければ 0.8） |
| `l` / `r` | 左旋回 / 右旋回 |
| `u` | 値で旋回 |
| `f` | 通常弾 |
| `F` | 拡散弾 |
| `C` | チャージ弾 |
| `S` | シールド |

### 制御

| 文字 | 意味 |
|------|------|
| `?` | pop が 0 なら次の1命令をスキップ |
| `j` | 相対ジャンプ |
| `[` `]` | ループ |
| `;` | コメント |

空白・改行は無視されます。

---

## サンプル

```
; 角度に応じて旋回し、距離があれば前進、正面なら撃つ
A
d 0 < ? r
A n 0 < ? l
D 2 0 0 > ? t
A a 0 . 2 < ? f
```
