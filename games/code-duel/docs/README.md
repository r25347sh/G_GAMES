# CODE DUEL - ゲーム説明書

**リアルタイム・プログラミング対戦ゲーム**  
WebRTC P2P / 2D物理演算 / 自律機体AIコーディングバトル

---

## これは何？

プレイヤーは自陣のテキストエディタで**オリジナルプログラミング言語**を使い、機体のAIをリアルタイムに記述・上書きします。

- `Ctrl + Enter` でコードを機体にデプロイ
- 相手のコードは画面の反対側に**透けて見える**
- 直接ダメージ指定は禁止。センサー・演算・制御構文・物理アクションを組み合わせて戦う

読み合いと対策コードの応酬が生まれる、プログラミング対戦です。

---

## 基本の遊び方

1. **HOST** ボタンを押してルームを作成
2. 表示された **Room ID** を相手に共有
3. 相手は Room ID を入力して **JOIN**
4. 言語を選択し、コードを書く
5. `Ctrl + Enter` または **RUN** でAIをデプロイ
6. 相手のコードを読みながらリアルタイムで対策を書く

## バトルフィールドのルール

| 要素 | 説明 |
|------|------|
| 機体 | 三角形。推力・旋回・弾・シールドで操作 |
| 物理 | 慣性・壁反射あり。急停止はできない |
| エネルギー (EN) | 行動で消費。時間経過で自然回復 |
| ヒート (HEAT) | 行動で上昇。高すぎると動きが鈍る |
| HP | 弾が当たると減少。0で敗北 |
| 壁 | アリーナ外周。反射する |

### 兵装

- **通常弾** … バランス型
- **拡散弾** … 近距離向き・3方向
- **チャージ弾** … 高威力・高消費
- **シールド** … 短時間ダメージ軽減

## 画面の見方

```
┌──────────────┬────────────────────┬──────────────┐
│  YOUR CODE   │    BATTLEFIELD     │  ENEMY CODE  │
│  (編集可能)   │   (物理演算空間)    │  (透けて表示) │
│              │                    │              │
│  言語選択     │   機体・弾・壁      │  相手の言語   │
│  RUN / STOP  │   HPバー           │              │
└──────────────┴────────────────────┴──────────────┘
```

- 左側：自分のコード
- 中央：戦闘空間
- 右側：相手のコード（リアルタイム同期）

---

## コツ

1. **最初は NoviceScript** で `chase` と `if front then fire` を試す
2. 相手のコードを読んで「いつ撃つか」「どう動くか」を予測する
3. エネルギーとヒートを意識する（連射しすぎると動けなくなる）
4. 壁を利用した反射や、距離を取った偏差射撃が強い

---

## 技術概要

- 通信: WebRTC (PeerJS)
- 描画: Canvas 2D
- 物理: 軽量カスタム2D
- ホスティング: GitHub Pages（ビルド不要）
