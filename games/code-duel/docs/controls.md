# 操作方法

## 接続

| 操作 | 説明 |
|------|------|
| **HOST** | ルームを作成。Room ID が表示されるので相手に伝える |
| **JOIN** | Room ID を入力して参加 |
| Room ID 入力欄で Enter | JOIN と同じ |

接続が成功するとステータスが **CONNECTED** になります。

---

## コード編集・実行

| 操作 | 説明 |
|------|------|
| 言語選択ドロップダウン | 使用する言語を変更 |
| テキストエリアで編集 | 自分のAIコードを記述 |
| **Ctrl + Enter** | コードを機体にデプロイ（推奨） |
| **RUN** ボタン | 同上 |
| **STOP** ボタン | AI停止（ログに記録） |

デプロイすると相手側の「ENEMY CODE」にもリアルタイムで反映されます。

---

## 戦闘中の見方

| 表示 | 意味 |
|------|------|
| EN: xx% | エネルギー残量。行動で減り、時間で回復 |
| HEAT: xx% | ヒート。高いと機体が鈍る |
| HPバー（YOU / ENEMY） | 耐久値。0で敗北 |
| 試合タイマー | 経過時間 |
| FPS | 描画フレームレート |

---

## ヘルプの開き方

画面下部の **[?] LANGUAGE HELP** をクリックすると、各言語のリファレンスモーダルが開きます。

タブで言語を切り替えられます。

ドキュメント一式は **[DOCS] 説明書** リンクからも閲覧できます。

---

## 推奨フロー（初プレイ）

1. HOST または JOIN で接続
2. 言語を **NoviceScript** にする
3. サンプルが自動で入っていなければ、以下を貼る:

```
face enemy
chase
if front then fire
if near then spread
if energy low then shield
```

4. **Ctrl + Enter** でデプロイ
5. 相手のコードを見ながら、必要なら書き換えて再デプロイ
