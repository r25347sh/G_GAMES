| Step | 内容 | 状態 |
|------|------|------|
| 1–4 | ロビー・機体操作・カメラ | 完了 |

## 操作
- WASD / 矢印 … 移動
- Shift / Space … ブースト
- Q / J / 右下タッチ … メイン武装
- F / K … サブ武装
- E / G / L … ガジェット
- 1 / 2 / 3 / 4 … 各武装・特殊コマンド切替
- R … 選択中の特殊コマンド

## 武装
メイン: バルカン / レーザー / プラズマ  
サブ: 追尾ミサイル / クラスター / EMP  
ガジェット: 機雷 / ステルス / チャフ / デコイ

## P2P 対戦
ルーム名とユーザー名を入力して「作成 / 参加」。PeerJS のシグナリングを使ってブラウザー同士を接続し、状態と攻撃イベントを WebRTC DataConnection で同期します。相手と同じルーム名・ルームキーを使ってください。ネットワーク接続には HTTPS または localhost が必要です。

## 隠しコマンド
入力は SHA-256 ハッシュ照合のみ。平文コマンドはソースに存在しません。  
テスト: キーボードで `TEST_ORBITAL_LASER` と入力 → 軌道レーザー。  
本番ハッシュ差し替えは `js/core/secret.js` の `SECRET_HASHES` を更新。
