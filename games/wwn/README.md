# 第n次世界大戦 (wwn)

| Step | 内容 | 状態 |
|------|------|------|
| 1–4 | ロビー・機体操作・カメラ | 完了 |
| 5–10 | 同期・武装10種・ミニマップ・最適化・隠しコマンド | 完了 |

## 操作
- WASD / 矢印 … 移動
- Shift / Space … ブースト
- J / 右下タッチ … メイン武装
- K … サブ武装
- L / Q / F … ガジェット
- 1 / 2 / 3 … メイン/サブ/ガジェット切替

## 武装
メイン: バルカン / レーザー / プラズマ
サブ: 追尾ミサイル / クラスター / EMP
ガジェット: 機雷 / ステルス / チャフ / デコイ

## 隠しコマンド
入力は SHA-256 ハッシュ照合のみ。平文コマンドはソースに存在しません。
テスト: キーボードで `TEST_ORBITAL_LASER` と入力 → 軌道レーザー。
本番ハッシュ差し替えは `js/core/secret.js` の `SECRET_HASHES` を更新。
