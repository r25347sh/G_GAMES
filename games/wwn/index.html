操作ガイド

機体操作

  • A / ← … 左回転のみ
  • D / → … 右回転のみ
  • ↑ … 前進（加速）
  • S / ↓ … 後退（通常より遅い）
  • B … ブースト（前進中に効果大）
  • 画面左タッチ … 仮想スティック（左右＝回転・上下＝前後）

武装キー

  • 1 切替 / Q 使用 … メイン
  • 2 切替 / W 使用 … サブ
  • 3 切替 / E 使用 … ガジェット
  • 右下タッチ … メイン連射（モバイル）

メイン武装

  • バルカン … 連射。ヒート上昇でオーバーヒートすると一時射撃不可。自然冷却。
  • レーザー … 瞬時着弾ビーム。エネルギー消費・自動回復。
  • プラズマ … 低速弾＋着弾時AoE爆風。エネルギー大消費。

サブ武装

  • 追尾ミサイル … 射程内敵を誘導。残弾制。
  • クラスター … 空中分裂子弾。残弾制。
  • EMPパルス … 周囲の操作・誘導・ブーストを一時麻痺。残弾制。

ガジェット（使用可否）

  • 空中機雷 … 後方設置。アーム後に近接起爆。残弾＋CD。CD中は不可。
  • ステルス … 一定時間半透明＆敵ミニマップ非表示。CDのみ（残弾なし）。CD中は不可。
  • チャフ … 短時間、誘導を阻害。残弾＋CD。
  • デコイ … 偽機影を放出。残弾＋CD。
  • 共通 … EMP麻痺中はガジェット使用不可。状態は画面下ヒントに表示。

HUD

  • Hull … 耐久。0で撃破→自動リスポーン
  • Boost / Heat / Energy … 各ゲージ
  • ミニマップ … 自機(金)・味方(シアン)・敵(ピンク)・機雷・デコイ

オープン乱戦ワールド

公式常設ルームへワンクリック参加。途中参加・自動リスポーン対応。

CPU対戦

ネットワーク不要。1対1 または 1対多数。
