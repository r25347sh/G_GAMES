操作ガイド

機体操作

  • A / ← … 左回転のみ
  • D / → … 右回転のみ
  • W / ↑ … 前進（加速）
  • S / ↓ … 後退（遅め）
  • B / Shift … ブースト
  • 画面左タッチ … 仮想スティック

武装キー

  • 1 切替 / Q or Space … メイン
  • 2 切替 / F … サブ
  • 3 切替 / E … ガジェット
  • 右半分タッチ … メイン連射

メイン武装

  • バルカン … 拡散連射。ヒート管理必須。
  • レーザー … 瞬時着弾。エネルギー制。
  • プラズマ … 爆風AoE。高火力。

サブ / ガジェット

  • ミサイル・クラスター・EMP（残弾は時間で回復）
  • 機雷・ステルス・チャフ・デコイ（CD/残弾/EMP中は不可）

マップギミック

  • 小惑星 … 衝突ダメージ。破壊でPT
  • 緑ゾーン … HP回復 / シアン … ブースト回復
  • 赤ゾーン … ダメージ / 金ゾーン … スコア
  • アイテム球 … HP・ブースト・弾薬・スコア

ポイント

  • 撃破 +100、小惑星 +15、拾得 +50
  • 連続撃破でコンボ倍率アップ
  • 全モードに弱めCPUが自動配置
